How to use

      

        Load the tile folder + your map template. Size the grid to match. Pick a terrain tile, click hexes to lay land.
        Switch to a River tile and draw along valleys — connecting pieces drop on neighbours automatically.
        Right-click erases. Pan with the ✋ tool / middle-mouse / Space+drag / scroll.
        Zoom with the on-screen − % + controls, Ctrl+scroll (zooms to cursor), +/−, or 0 to fit the whole map.
        v2: viewport culling + a colour overview when zoomed out, diff-based undo, and compressed saves — built for very large maps.
